# 카툰 그림: 조각을 조립해 앱에서 그린 컷 (2026-11-12)

상세안 시안의 그림 조각(차의 표정, 배경, 소품)을 앱(Compose Canvas)으로 옮긴 뒤 에뮬레이터에서 눈으로 확인한 기록이다.
에뮬레이터 Pleos Connect v2.1.0, debug 빌드, 앱 창 1682×1210. 확인용 화면은 debug 전용 `CartoonGalleryActivity`.

## 확인한 것

- 시안과 같은 그림이 앱에서 그려진다: 비, 해 질 녘, 밤(달·별), 주차(노란 주차선, 화살표 수 = 기어를 바꾼 횟수), 묻고 답하기(흰 말풍선과 노란 말풍선), 급하게 선 순간, 세게 밟은 순간, 표정 8가지.
- 글은 차량 시스템 글꼴(Asta Sans)로 나온다. 컷 아래 글 26sp, 근거 24sp.
- 고친 것: 효과 글자 "끼익"이 컷 번호와 겹쳤다(`screens/01`). 글자를 오른쪽으로 옮겼다(`screens/04`). "쓱", "덜"도 같이 옮겼고 시안도 같게 고쳤다.
- 전체 단위 테스트 381개 통과, lintDebug 통과(2026-11-12 21시).

## 아직 못 본 것

- 블랙 테마와 좁은 창(840dp)에서의 모습.
- 실제 주행 기록으로 만든 화(지금은 확인용으로 넣은 재료).

## 이 그림 방식의 한계(사용자 지적, 같은 날)

정해 둔 조각을 조립하는 방식이라 경우의 수가 한정되고, 도형으로 그린 차라 그림 수준이 낮다.
사용자가 "그때그때 맞춰 생성하는 방식으로, 그림 수준을 올려서, 차의 생각도 다양하게"로 방향을 정했다.
이 조립 그림은 생성이 안 될 때(인터넷 없음, 서비스 실패)의 예비로 남긴다.

> 뒤에 바뀐 것: 생성형 AI로 그리는 방식은 그림 모델에 무료 사용분이 없고 통신과 서버가 있어야 해 1차에서는 접고 발전 계획으로 뒀다. 3D 그림(`../2026-11-12-3d-art`)을 거쳐, 지금 앱은 이 조립 방식을 다시 그린 2D(`../2026-11-13-chatoon-2d`)를 쓴다.
