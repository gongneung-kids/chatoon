# 차툰 release(R8) 최종 확인 4차 (2026-11-13 밤, 커밋 25fdcdc0)

이름 전환(`kr.chatoon.app`, 새 서명 키 CN=Chatoon), 공조 사건, 옛 수집 삭제, 화면 개선(운전 시간·차가 본 것 칩·구도 변화·앞뒤 화)이 모두 들어간 빌드다.

## 방법

1. debug 앱을 지우고 release 설치(`pkgFlags`에 DEBUGGABLE 없음).
2. **앱을 띄우기 전에** 속도 권한과 알림 권한을 `pm grant`로 줌(3차에서 앱이 켜진 뒤 주면 급정거가 세어지지 않았다).
3. 앱 실행 → 소개 「시작하기」 → 「동의하고 시작하기」(`../2026-11-13-chatoon-release-3/scripts/tap.py`).
4. `scripts/release_drive4.py`: 출발 22도·열선 끔 → 와이퍼, 창문 100% 70초, 달리다 26도·열선 2단, 급정거(초당 10km/h), R·D·R → P.
5. 보기 「누가 끼어들어서」 누르기.
6. 앱 다시 시작 → 60초 대기 → `vc.py measure 60` 두 번(이번 측정은 와이퍼·창문·공조 온도·주행거리·속도를 바꿈).

## 이 확인에서 찾아 고친 것

- 질문 카드가 떠 컷이 작아지면 4컷 차의 생각이 「…다음엔 조금만 …」처럼 잘림 → 앱 담당 세션이 글 칸을 늘려 고침.
- 보기 「앞차가 갑자기」가 '갑자기'에 걸려 「앞에 뭔가 갑자기 나타났다고 한다」로, 「누가 끼어들어서」도 같은 갈래(제목 「갑자기 나타난 것」)로 읽힘 → 이유 두 가지를 더해 「앞차가 갑자기 선 날」, 「누가 끼어든 날」(3d352ae3). 이 캡처의 제목은 고치기 전이다.
