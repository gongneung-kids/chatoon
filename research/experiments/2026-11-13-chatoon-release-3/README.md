# 차툰 release(R8) 확인 3차 (2026-11-13, 커밋 cac11302)

그림을 코드로 그리는 2D, 창문·공조·열선 기록, 처음 소개 화면이 들어간 동결 커밋 cac11302를 release로 빌드해 확인했다. 그 뒤 사용자 지시로 공조 사건(0f3fd121)과 이름 전환(681a8c9b, 패키지 `kr.chatoon.app`, 새 서명 키 CN=Chatoon)이 더해져, 최종 확인은 4차에서 다시 한다.

## 방법

1. debug 앱을 지우고 release 설치(서명 확인, `pkgFlags`에 DEBUGGABLE 없음).
2. 앱 실행 → 소개 화면 → 「시작하기」 → 「동의하고 시작하기」(`scripts/tap.py`: uiautomator로 글자를 찾아 누름).
3. 속도 권한을 `pm grant`로 줌 → 알림 권한 「허용」.
4. `scripts/release_drive3.py`: 와이퍼 Low, 열선 2단, 공조 17도·풍량 최대, 창문 100%로 70초, 60→20km/h를 초당 10km/h로 줄임(급정거), R·D·R → P.
5. `vc.py measure 60`.

- 성능은 반드시 **앱 시작 → 60초 대기 → `measure 60`** 순서로 잰다. 시작 직후에 재면 기준(5%)을 넘는 값이 나온다.
