# 실험 기록

검증하며 만든 데이터(화면 캡처, 화면 글자 덤프, 로그, 주행 입력·감시 기록, 결과 표)를 버리지 않고 여기에 모읍니다.
실험 하나에 폴더 하나(`<날짜>-<주제>/`)를 두고, 아래 색인에 한 줄씩 덧붙입니다. 오래된 기록도 지우지 않습니다.

폴더 구성(실험마다 같은 이름을 씀)

| 폴더 | 내용 |
|---|---|
| `screens/` | 에뮬레이터 전체 화면 캡처(2560×1440). 이름 앞 번호가 실험 순서 |
| `dumps/` | 같은 이름 캡처를 찍은 순간의 화면 글자와 위치(uiautomator, 사용자 10) |
| `traces/` | 주행 입력·감시 기록(CSV)과 회차별 결과 요약 |
| `logs/` | logcat 발췌, `dumpsys` 결과 |
| `scripts/` | 그 실험에 실제로 쓴 스크립트(재현용) |
| `README.md` | 목적, 빌드, 방법, 결과, 찾은 문제, 고친 커밋 |

시연 영상(mp4)처럼 큰 파일만 커밋하지 않습니다.
