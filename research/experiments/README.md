# 실험 기록

차툰을 만들며 Pleos Connect v2.1.0 에뮬레이터에서 직접 확인한 기록입니다. 실험 하나에 폴더 하나(`<날짜>-<주제>/`)이고, 오래된 기록도 지우지 않습니다.
그래서 지금 앱과 달라진 방식(3D 그림 등)의 기록도 남아 있습니다. 지금 앱이 어떤지는 맨 아래 세 줄(release 확인 4차, 제출 APK 확인)을 보면 됩니다.

폴더마다 `README.md`(목적, 방법, 결과, 찾아 고친 것)가 있고, 필요한 만큼 `screens/`(에뮬레이터 캡처. 전체 화면 2560×1440 또는 앱 창 1682×1210), `logs/`(logcat 발췌, `dumpsys` 결과), `scripts/`(그 실험에 쓴 스크립트)가 붙습니다. 영상 원본처럼 큰 파일은 올리지 않습니다.
