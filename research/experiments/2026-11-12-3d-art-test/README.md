# 3D 그림 시험: Blender로 만든 차와 거리를 미리 렌더해 쓸 수 있는가 (2026-11-12)

> 이 방식은 쓰지 않습니다. 11-13에 앱 코드로 그리는 2D와 나란히 비교한 뒤 3D를 지웠습니다(`../2026-11-13-chatoon-2d`). 지금 앱에는 그림 파일이 없습니다.

차툰의 그림을 더 좋게 하려고, 지금의 벡터 그림(Compose Canvas) 대신 3D로 만든 장면을 미리 렌더해 앱에 넣는 방식을 시험했다. 외부 그림이나 3D 모델을 가져오지 않고, Blender에서 도형(둥글린 상자, 공, 원통, 고리)만 조합해 차와 사람, 도로, 건물, 나무를 만들었다.

## 방법

- Blender 5.2.2, 렌더 엔진 EEVEE, 1200×900. 장면 전체를 `car_test.py` 하나가 만든다.
- 실행: `blender -b -P car_test.py -- <나올 파일.png> <차 색 #rrggbb> <day|dusk|night>`
- 한 장에 약 12초(이 컴퓨터 기준).

## 결과

| 파일 | 차 색 | 시간 |
|---|---|---|
| `day-red.jpg` | 빨강 `#E8503A` | 낮 |
| `dusk-blue.jpg` | 파랑 `#3D7BE8` | 해 질 녘 |
| `night-white.jpg` | 흰색 `#F2F2F0` | 밤(건물 창과 가로등 불빛) |

- 차 색을 값 하나로 바꿀 수 있다. 시간에 따라 하늘색, 햇빛 색과 각도, 창문 불빛이 달라진다.
- 앞유리 너머로 운전석의 사람이 보인다.

## 아직 안 한 것

- 표정(지금은 웃는 얼굴 하나), 구도(지금은 비스듬한 앞모습 하나), 비.
- 앱에 넣는 것. 컷마다 필요한 그림 수와 앱 크기는 따져 보지 않았다.
- 사람과 차의 모양 다듬기.
