# 차툰 2D 그림 전면 개발 (2026-11-12 밤 ~ 11-13, 사용자 결정 "3d 다 폐기하고 2d 전면적으로 개발해")

3D(Blender 미리 렌더, 그림 198장)를 지우고 Compose Canvas 2D로 다시 그렸다. 에뮬레이터 debug 갤러리(`CartoonGalleryActivity`, 사례 16개)와 앱 이번 화로 확인.

| 반영한 지적 | 2D에서 |
|---|---|
| 퀄리티(그림 수준 낮음) | 차체 그늘·반사광, 유리 그라데이션, 바닥 그림자, 원근감 있는 도로·인도, 가로수·가로등 |
| 차 색 설정 | 고른 색에서 그늘·반사광을 만들어 칠함 |
| 안에 탄 사람이 잘 보이게 | 앞유리 너머 운전자(머리카락·얼굴·어깨·핸들 잡은 두 손), 옆모습 운전자·뒷좌석 손님(머리카락·얼굴·옷 색) |
| 도로·비·날씨·시간별 하늘 | 낮·해 질 녘·밤(별·달·불 켜진 창·전조등 불빛)·비(구름·빗줄기·물웅덩이·큰비 물튀김) |
| 컷마다 다른 배경 | 출발 = 집 앞 골목(대문·전봇대), 달리는 장면 = 도로, 주차장, 마지막 컷 = 도착지(집·회사·병원·마트·카페·자연) |
| 밤 눈 모양 | 두 눈이 늘 같은 시선, 빛 번짐은 작고 옅게, 감은 눈에는 없음 |
| 급가속·급정거 구별 | 급정거 = 정면, 앞이 숙여짐, 바퀴 자국·연기, 끼익 / 급가속 = 옆모습, 앞이 들림, 속도선·먼지, 부웅 |
| 후면·전면 주차 | 위에서 본 차의 전조등 방향으로 구별 |
| 말풍선 | 컷마다 차의 짧은 말(규칙 엔진 Cut.say, 주인의 말이 아님), 꼬리 끝이 차의 지붕선에 닿게 |
| 옆모습이 뒤로만 길다 | 정면과 비율을 맞춘 짧은 해치백 |
| 사이드미러 | 정면·옆모습·위에서 본 모습 모두 |
| 거울이 귀처럼 보임(직접 찾음) | 앞유리 아래 옆의 작은 미러로 |

확인 못 한 것: release(R8)에서 2D 그림, 성능 재측정(그림 파일이 없어져 메모리는 줄어들 것으로 보이나 재지 않음), 실차.
