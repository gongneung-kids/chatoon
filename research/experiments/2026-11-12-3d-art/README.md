# 3D 그림을 앱에 넣기 (2026-11-12)

벡터 조각 그림(Compose Canvas) 대신, Blender로 만든 3D 장면을 미리 렌더해 앱에 담고 겹쳐 그린다. 외부 그림·3D 모델·생성형 AI는 쓰지 않았다(도형만으로 만든 장면, `tools/art/chatoon_art.py`).

## 만든 것

- 그림 162장(webp, 2.7MB, 800×600): 구도 5가지(정면, 얼굴 가까이, 놀란 순간, 묻는 장면, 주차장 위) × 시간 3가지(낮, 해 질 녘, 밤). 배경은 맑음·비 두 벌, 차는 표정 8가지(구도에 따라 1~8가지).
- 한 컷은 세 겹: 배경(길·하늘·차의 그림자), 차체(흰색), 나머지(유리·바퀴·눈과 입·타고 있는 사람). 앱이 차체 겹에 고른 차 색을 곱한다(`CarPaint` 11가지, `LocalCarPaint`).
- 그림 위에 앱이 그리는 것: 빗줄기(자리·길이·밝기를 흩뜨림, 세게 오면 길바닥 물방울), 효과 글자(끼익, 부웅), 말풍선, 주차 기어 화살표.
- 비 오는 날 배경은 하늘을 흐리게, 길을 젖어 반사되게 렌더했다. 밤에는 건물 창과 가로등, 전조등이 켜진다.
- 그림이 없는 컷(와이퍼 가까이, 옆모습, 공조 온도)은 예전 벡터 그림으로 그린다. 이 컷들은 아직 실제 주행에서 나오지 않는다.

## 확인

- debug 빌드, 확인용 화면(`CartoonGalleryActivity --es paint <색>`)으로 캡처. 커밋 43e9ddf1 위에 그림 변경만 얹은 별도 작업 폴더에서 빌드했다.
- 단위 테스트 212개 통과(그림 테스트 `PanelArtTest` 6개 포함: 컷마다 세 겹 파일이 다 있는지, 쓰지 않는 파일이 없는지), lintDebug 통과.
- `03`은 고치기 전 캡처다. 묻는 컷에서 차가 말풍선에 가리고, 빗줄기가 격자처럼 보이고, 주차장 옆 차가 우리 차 색과 헷갈려서 고쳤다(`01`, `02`, `04`가 고친 뒤).

## 급정거와 급가속을 다른 그림으로 (같은 날 밤, 사용자 지적)

사용자 지적: 급가속(부웅) 컷이 정면에서 놀란 얼굴이라 급정거처럼 보인다. 둘이 그림만 봐도 반대로 보여야 한다.

- 급정거(`brake`): 비스듬히 앞에서 본 차가 앞으로 숙여지고, 뒤에 바퀴 자국과 타이어 연기가 남는다. 운전자는 앞으로 쏠린다. 그림 위에 "끼익"과 느낌표.
- 급가속(`accel`): 옆에서 본 차가 앞바퀴가 들린 채 오른쪽으로 튀어 나가고, 뒤로 먼지가 날린다. 운전자는 등받이로 밀린다. 그림 위에 왼쪽으로 흐르는 속도선과 "부웅".
- 낮은 구도에서 길 밖이 비어 보이지 않게 길 앞쪽에도 보도를 더했다.
- `05`가 앱 화면, `06`이 렌더 원본. 테스트 213개 통과(급정거·급가속이 다른 그림인지 보는 테스트 1개 더함), lintDebug 통과.

## 컷마다 다른 무대, 두 눈의 시선, 주차 방향 (같은 날 밤, 사용자 지적)

사용자 지적: "야간 만화 볼 때 차량 눈알이 이상하다", "배경이 다 똑같은데 만화마다 컷마다 달라야", "후면주차인지 전면주차인지 디테일도 챙겨야".

- 눈: 눈동자를 차 앞쪽에만 붙여서, 비스듬한 구도에서 먼 쪽 눈과 가까운 쪽 눈의 시선이 달라 짝짝이로 보였다. 두 눈이 같은 점(차 앞과 보는 사람 사이)을 보게 눈동자 자리를 계산하도록 고쳤다.
- 무대: 출발 컷은 집 앞 골목(낮은 집과 지붕, 담장, 화분, 전봇대), 달리는 컷은 도로, 주차 컷은 주차장, 마지막 컷은 주인이 말한 행선지(아파트 단지, 유리 빌딩, 병원, 마트, 카페 거리, 산과 숲). 모르면 도로.
- 주차: 후면 주차면 차 앞이 통로 쪽인 그림, 전면 주차와 모를 때는 차 앞이 벽 쪽인 그림.
- 그림 198장, 3.1MB. 테스트 221개 통과(배경·주차 방향 테스트 포함), lintDebug 통과. `07`이 앱 화면, `08`이 렌더 원본.
